# Artificial Intelligence

## Assignments

### Assignment 1: Optimization & Class Imbalance
*   Analyzed and compared the mathematical intuition of SGD+Momentum, Adagrad, and RMSprop optimizers.
*   Implemented the Synthetic Minority Oversampling Technique (SMOTE) to handle class imbalance and built a Deep Neural Network classifier to evaluate its effectiveness with different optimizers.

### Assignment 2: Classical Machine Learning
*   Provided detailed numerical, manual examples and code explanations for core ML algorithms: K-Nearest Neighbors (KNN), Support Vector Machines (SVM) with RBF kernel, Gradient Boosted Trees (GBT), and Extreme Gradient Boosting (XGBoost).

## Projects

### Project 1: Deep Learning for Computer Vision
*   **Part I: CNN & Transfer Learning:** Implemented and compared VGG16 and ResNet50 architectures for multi-class skin disease classification, analyzing the impact of data augmentation on model performance.
*   **Part II: Generative Adversarial Networks (GANs):** Built a Deep Convolutional GAN (DCGAN) on the CIFAR-10 dataset and provided a mathematical explanation for the superiority of the alternative generator loss function.
*   **Part III: Transfer Learning Strategies:** Demonstrated and coded different transfer learning approaches (fine-tuning vs. feature extraction) for scenarios with small datasets similar to or different from the pre-trained model's original data.

### Project 2: Unsupervised, Supervised & Quantum Learning
*   **Part I: Unsupervised Learning:** Explained Hierarchical and DBSCAN clustering mathematically. Applied and compared K-Means, Hierarchical, and DBSCAN on a financial dataset for investor segmentation.
*   **Part II: Supervised Learning:** Elucidated the Gini Impurity Index and compared it with Entropy for Decision Tree splits. Built and evaluated Decision Tree and Random Forest models for classification and regression tasks.
*   **Part III: Quantum Computing:** Implemented Basis and Amplitude encoding methods using Qiskit to load classical data into quantum states. Built and explained a Quantum Neural Network (QNN) model.

### Project 3: Reinforcement Learning & Advanced Networks
*   **Part I: Reinforcement Learning:** Explained Policy Iteration with a manual example. Coded and optimized a Deep Q-Network (DQN) for the CartPole environment and developed a neural network-based Q-learning agent for the FrozenLake game.
*   **Part II: RNN & LSTM:** Provided a complete mathematical breakdown of LSTM gates and backpropagation. Improved the performance of existing RNN and LSTM models for time-series forecasting.
*   **Part III: Search Algorithms:** Implemented and demonstrated A* search, Minimax, DFS, BFS, and Uniform Cost Search (UCS) with Python scripts. Solved a constraint satisfaction problem (map coloring) using a backtracking algorithm.
